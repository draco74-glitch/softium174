# Что сделано и что осталось сделать вручную

## Осталось сделать вам
1. **Шрифт (латиница, цифры, ₽).** Скачайте latin-подмножество Nunito (fonts.google.com → Nunito → Download, либо fontsource.org/fonts/nunito), переименуйте в `assets/fonts/nunito-latin.woff2`, положите в `assets/fonts/` и раскомментируйте блок в `assets/fonts/fonts.css`. Без этого цифры и латиница рисуются системным шрифтом.
2. **Цели в Яндекс.Метрике** (счётчик 114139660 → Цели → JavaScript-событие). Идентификаторы: `phone_click`, `messenger_click`, `cta_click`, `form_view`, `video_play`, `doc_open`. Цель «заявка отправлена» настройте в самой Яндекс.Форме (Настройки → Яндекс.Метрика → цель при отправке).
3. **Яндекс.Форма**: оставьте поля «Имя», «Телефон», «Возраст ребёнка». Включите уведомление в Telegram/на почту.
4. **Фото**: добавьте настоящие фото класса Челябинска. Сейчас в hero и видео — кадры из общего ролика сети.
5. **Расписание** меняется в 4 местах: `index.html` (hero-note, блок «Пробное», «Когда», контакты), FAQ, и в `build_pages.py`-текстах страниц возрастов (или правкой самих html).
6. Отправьте новый `sitemap.xml` в Яндекс.Вебмастер.
